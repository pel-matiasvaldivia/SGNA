# Dependencias directas, con versión fija.
#
# Antes todas eran `>=` sin tope y cada reconstrucción de la imagen podía traer
# un major nuevo. Así se cayó producción: SQLAlchemy 2.1 cambió el driver por
# defecto de `postgresql://` de psycopg2 a psycopg (v3), que no está instalado,
# y el backend dejó de arrancar. Las versiones de acá son las que resolvió ese
# build y quedaron validadas por las suites de backend/tests.
#
# Este archivo lista lo que el proyecto usa de forma directa. La imagen se
# construye desde requirements.lock.txt, que además fija las transitivas: sin
# eso el congelado es incompleto (starlette, por ejemplo, entra por fastapi y
# puede romper por su cuenta).
#
# Para subir una dependencia, a propósito y no por accidente:
#   1. cambiar la versión acá
#   2. pip install -r requirements.txt && pip freeze > requirements.lock.txt
#   3. correr las suites de tests/ contra un Postgres de prueba
#   4. commitear los dos archivos juntos
